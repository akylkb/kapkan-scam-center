# Экранный реквизит · сериал «Капкан»

Интерфейсы подпольного колл-центра для съёмок. Работающего бэкенда нет и не
предполагается: задача — картинка, которая держит крупный план и читается
на общем.

Все бренды, имена, телефоны и номера счетов вымышленные. Приложение не ходит
в сеть и не обрабатывает никаких реальных данных.

---

## Запуск на площадке

```bash
npm install          # один раз, нужен интернет
npm run build        # один раз, нужен интернет
npm start            # на площадке; интернет НЕ нужен

python3 -m http.server 8080
```

`npm run build` кладёт всю декорацию в папку `out/` готовыми HTML-файлами:
после сборки ни Next, ни сборщик на площадке не нужны, `npm start` только
раздаёт эти файлы. Папку `out/` можно целиком скопировать на флешку и
запускать на любой машине — важно лишь, чтобы её отдавал какой-нибудь сервер,
а не открывали двойным кликом (`file://` не подхватит стили и шрифты).

Сервер поднимается на `http://localhost:3000`. Если снимаете с нескольких
машин, поднимите его на одной и раздайте остальным по локальной сети:

```bash
PORT=3000 npm start
# на остальных машинах открывайте http://<ip-ведущей-машины>:3000
```

Стартовая страница `/` — служебный пульт запуска: выбираете экран, номер
места, нажимаете. В кадр она не попадает.

### Полноэкранный режим

`F11` в любом браузере. Надёжнее — сразу запускать в киоске:

```bash
# macOS
open -na "Google Chrome" --args --kiosk --disable-infobars "http://localhost:3000/crm/3/"

# Windows
chrome.exe --kiosk --disable-infobars "http://localhost:3000/crm/3/"
```

## Экраны

| Адрес | Что это | Куда ставить |
|---|---|---|
| `/crm/N/` | Рабочее место оператора | Все 10 машин в зале, **у каждой свой N** |
| `/drops/N/` | Рабочее место дроповода | Отдел вывода, **у каждой машины свой N** |
| `/chat/N/` | Рабочее место чатера (мессенджеры) | Отдел переписки, **у каждой машины свой N** |
| `/victim/N/` | Телефон жертвы — живая переписка с `/chat/N/` | Вторая машина в паре к чатеру |
| `/wall` | Дашборд на стену | Плазма/проектор, общий план |
| `/client` | Кабинет «брокера» глазами жертвы | Ноутбук жертвы, сцены с демонстрацией экрана |
| `/admin` | Панель супервайзера | Экран главного |

### Про `seat`

Номер места — не украшение. Он определяет имя оператора, его лиды, суммы и
таймер звонка; у дроповода — пул карт, банки, города и состояние кассы;
у чатера — схему работы (товарка, доставка, банк-СБ, романтика, крипта),
набор личин-аккаунтов и то, какой диалог открыт при запуске.
Если открыть на всех десяти машинах один и тот же адрес, в
общем плане будут десять одинаковых экранов, и сцена сразу читается как
декорация. Раздайте `/crm/1/` … `/crm/10/`.

При этом данные детерминированы: `/crm/3/` всегда показывает одно и то же.
Дубль 1 и дубль 7 совпадут, монтаж склеится.

Мест собирается 99 — если понадобится больше десяти машин, лишние адреса
уже лежат в сборке. Старые ярлыки вида `/crm?seat=3` тоже работают: такой
адрес сам перекидывает на `/crm/3/`.

## Живая переписка: чатер и телефон жертвы

`/chat/N/` и `/victim/N/` — две половины одного разговора. Что напечатал
актёр-чатер, тут же появляется на телефоне жертвы, и наоборот. Играется
вживую, а не отыгрывается по хоткеям.

**Номер места должен совпадать.** `/chat/3/` разговаривает только с
`/victim/3/`. Разные номера — два разных, не связанных между собой разговора.

```bash
# на ведущей машине
PORT=3000 npm start

# машина чатера        →  http://<ip-ведущей>:3000/chat/3/
# машина жертвы        →  http://<ip-ведущей>:3000/victim/3/
```

Обе машины должны открывать адрес **одного и того же** сервера. Если на второй
машине открыть свою копию `npm start`, экраны друг друга не увидят.

Как это работает: связь идёт по локальной сети через тот же сервер, что раздаёт
страницы (адрес `/live`). Наружу, в интернет, не ходит ничего — площадке
по-прежнему достаточно локалки без выхода в сеть.

### Что умеет пара

- **Телефон сам следует за чатером.** Оператор кликнул другой диалог — телефон
  мгновенно перерисовался под нового собеседника, с его именем и историей.
  Настраивать ничего не нужно.
- **«Печатает…»** видно на обоих экранах, гаснет через три секунды тишины.
- **Две галочки** у реплики чатера загораются, когда телефон её получил.
- **Кнопки доказательств** («Чек», «Трек», «Баланс», «Фото», «Ссылка») слева от
  поля ввода отправляют вложение — оно всплывает на телефоне.
- **Тап по фишинговой ссылке на телефоне** делает ровно то же, что `Ctrl+Alt+9`:
  у чатера диалог уходит в этап «СПИСАНИЕ», открывается перехват SMS-кода,
  а на стену и в тикер идёт списание.
- **Хоткеи режиссёра работают на обе машины.** `Ctrl+Alt+R` сбрасывает дубль
  сразу на обоих экранах, `Ctrl+Alt+1` — телефон жертвы звонит.

### Если экраны не видят друг друга

В левом нижнем углу телефона есть тусклая служебная строка (в кадр не попадает).
Она показывает режим связи:

| Строка | Что значит | Что делать |
|---|---|---|
| `МОСТ · СЕТЬ` | Всё в порядке, машины связаны | — |
| `МОСТ · ВКЛАДКИ` | Связаны только окна этой машины | Обе машины должны открывать адрес одного сервера, а не каждая свой |
| `МОСТ · НЕТ` | Связи нет вообще | Очень старый браузер — возьмите Chrome |

Там же видно `СЛЕДУЮ ЗА ОПЕРАТОРОМ` (чатер на связи) или `ОПЕРАТОР НЕ В СЕТИ`
(экран чатера ещё не открыт — телефон показывает стартовый диалог).

Порядок включения машин значения не имеет: пока чатер не запущен, оба экрана
и так открыты на одном и том же диалоге. Перезагрузка `F5` посреди дубля тоже
не страшна — сервер помнит переписку смены и доиграет её заново.

## Режиссёрский пульт

Горячие клавиши работают на любом экране. Визуального отклика у самого
нажатия нет — в кадре оно незаметно.

| Клавиши | Что происходит |
|---|---|
| `Ctrl+Alt+1` | Входящий звонок: софтфон поднимает трубку, таймер с нуля |
| `Ctrl+Alt+2` | **Депозит зачислен** — зелёная вспышка, счётчики скачут, событие в ленте |
| `Ctrl+Alt+3` | Клиент сорвался: строка краснеет, звонок обрывается |
| `Ctrl+Alt+4` | **VIP-кит** — крупный депозит, лидерборд на стене перестраивается |
| `Ctrl+Alt+5` | Запрос на вывод: у жертвы всплывает требование «налога 10%» |
| `Ctrl+Alt+6` | **ТРЕВОГА / рейд** — всё краснеет, домен заблокирован (повторно — выключить) |
| `Ctrl+Alt+7` | Дроп сгорел: выбранная карта краснеет, заливы по ней срываются |
| `Ctrl+Alt+8` | **Залив ушёл** — цепочка отмыва закрывается, касса прыгает вверх |
| `Ctrl+Alt+9` | **Жертва открыла ссылку** — у чатера растёт счётчик переходов, в переписку падает строка «введены данные карты», в панель перехвата прилетает свежий SMS-код |
| `Ctrl+Alt+B` | Личину забанили: аккаунт чатера краснеет, поле ввода блокируется |
| `Ctrl+Alt+0` | Стоп-кадр: заморозить все анимации (для установки света) |
| `Ctrl+Alt+R` | **СБРОС ДУБЛЯ** — вернуть исходное состояние |

На экране чатера работают и общие клавиши: `Ctrl+Alt+2` закрывает диалог
оплатой, `Ctrl+Alt+3` зажигает красный детектор «палева» и подсвечивает
стоп-слова в реплике жертвы, `Ctrl+Alt+1` переключает панель инструментов
на подмену голоса и запускает таймер звонка с нуля.

**`Ctrl+Alt+R` перед каждым дублем.** Без сброса таймеры и суммы уедут, и
кадры не состыкуются на монтаже.

Вкладки на одной машине синхронизируются автоматически. Между разными
машинами — нет: события нажимаются на той машине, которая в кадре.

## Чек-лист перед сменой

1. `npm run build` дома, с интернетом. На площадке — только `npm start`
   (или скопированная папка `out/` и любой статический сервер).
2. Проверить, что все машины открыты с **разными** номерами мест в адресе.
   Исключение — пара чатер/жертва: у `/chat/N/` и `/victim/N/` номер общий.
3. Полноэкранный режим на каждой (`F11`), закладки и панель Chrome убраны.
4. Прогнать хоткеи на одной машине, убедиться, что реагирует.
5. Если в сцене есть живая переписка — написать пробную реплику в обе стороны
   и убедиться, что в углу телефона горит `МОСТ · СЕТЬ`.
6. `Ctrl+Alt+R` — и можно снимать.

## Структура кода

```
app/                  семь экранов + служебный лаунчер
                      (crm|drops|chat|victim)/[seat]/ — по странице на место
scripts/serve.mjs     съёмочный сервер: раздаёт out/ и держит мост, без зависимостей
components/
  crm/                рабочее место оператора
  drops/              рабочее место дроповода (карта снятий считается программно)
  chat/               рабочее место чатера
  victim/             телефон жертвы — вторая половина живой переписки
  wall/               дашборд на стену (карта мира считается программно)
  client/             кабинет жертвы
  admin/              панель супервайзера
  shared/             тикер, часы, вспышки событий, базовые элементы
lib/
  brand.ts            ВСЕ названия в кадре — менять только здесь
  prng.ts             детерминированный генератор (см. «Про seat»)
  format.ts           деньги, время, маскировка телефонов и карт
  fixtures/           генераторы лидов, операторов, свечей, дропов, заливов
  live/               живая связь между экранами (см. «Живая переписка»)
  scene/              часы сцены, шина событий, горячие клавиши
```

### Если нужно переименовать бренды

Всё лежит в [lib/brand.ts](lib/brand.ts): CRM `VORTEX·TS`, «брокер»
`AURUM CAPITAL`, контора `MERIDIAN GROUP`, платёжка `PayNordic`, VoIP
`TALKGRID`, софт удалённого доступа `REMOTEVIEW`, панель вывода `TRANZIT·OPS`,
обменник `SWIFTBIT`, кошелёк-накопитель `COLDNEST`. Правится за минуту.

На экране дроповода дополнительно: номера карт показываются только последними
четырьмя цифрами, адреса кошельков — с закрытой серединой. Полный номер карты
или валидный крипто-адрес в кадр не попадает даже на стоп-кадре.

### Достоверность

Устройство интерфейсов опирается на материалы расследований OCCRP
(«Fraud Factory», «Scam Empire») и Qurium: разделение на конверсию и
ретеншн, работа операторов под псевдонимами, карточка клиента с полями
о капитале и опыте инвестиций, встроенная в CRM дорисовка депозитов,
блокировка выводов под предлогом налога, удалённый доступ к экрану жертвы,
лидерборды и запись всех разговоров.

Отдел вывода воспроизведён по той же логике: пул подставных карт с суточными
лимитами, процент дропа, перехват СМС-подтверждений, дробление суммы по
цепочке «дроп → обменник → криптокошелёк → наличные» и курьеры, забирающие
нал в разных городах.
